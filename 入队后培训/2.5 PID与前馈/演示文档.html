输出限幅（Output Limit）

为什么需要

PID 输出可算到任意大，但电机最大电流 / 电压有限。超出部分不会生效，执行器长期被顶死在极限值——输出失真，还给积分饱和埋下伏笔。

怎么做

把控制量钳位（clamp）到执行器能力范围：u = clamp(u, −u_max, +u_max)。u_max 按电机手册最大值设定并留余量。

限幅是「保护电机 + 保护控制效果」的第一道护栏；输出被限幅后积分仍会累积——见下页积分饱和。

积分限幅与积分饱和（Windup）

积分饱和是什么

误差长时间存在（大阶跃、堵转）时 I 项持续累积，像雪球越滚越大，远超输出限幅允许的量。误差回零后输出仍长时间顶在限幅值 → 大超调、来回振荡。

解法：两件套缺一不可

① 积分限幅：|∫e| ≤ int_max，管住雪球大小；
② 抗积分饱和（Anti-Windup）：输出饱和时停止 / 回退积分（条件积分或反计算法），管住雪球继续滚。

一句话：限幅管住「攒多少」，抗饱和管住「什么时候别再攒」。第 14 页仿真器可关闭抗饱和观察振荡。

微分噪声（Derivative Noise）

问题

位置信号带编码器毛刺（量化台阶、机械振动）。D 项对误差求导会放大高频噪声，输出剧烈抖动 → 云台高频抽搐、有电流声。

解法

① 误差先一阶低通滤波再差分（不完全微分）；
② 直接使用陀螺仪角速度代替位置差分，免去求导。滤波系数需在「干净」与「跟手」之间试出。

一句话：对带噪声的信号求导 = 放大噪声；先滤波再求导（或用陀螺仪），D 项才敢用。

串级 PID：外环发令，内环执行

θ* →(±)→ [位置环 PID] → ω* →(±)→ [速度环 PID] → u → [电机+云台] → ω → θ
       ↑                                  ↑                                │
       └─────── 实际角度 θ（编码器） ──────┴── 实际角速度 ω（陀螺仪） ──────┘

内外环职责（云台 Pitch）

外环（位置环）：输入 eθ = θ* − θ，输出目标角速度 ω*；
内环（速度环）：输入 eω = ω* − ω，输出电机电流 u。
核心：外环输出 = 内环目标。

为什么抗干扰强 / 怎么整定

扰动先改变角速度 → 内环立即抵消，位置几乎不动；单环须等位置误差出现才反应。
整定顺序：先内后外；外环常用 P 或 PI，少用 D。

串级结构动画：扰动刚冒头就被内环吃掉

外环输出 = 内环目标（目标角速度）；下方曲线观察扰动被内环吸收

「环」= 反馈什么量

环反馈量输出机器人的使用
电流环电流（力矩 ≈ 电流）电压 / PWM电机驱动内部，我们一般不碰
速度环转速 / 角速度电流摩擦轮、底盘
位置环角度 / 位置目标速度云台 Pitch / Yaw
  • 云台 Pitch / Yaw：位置环套速度环（串级）；摩擦轮：仅速度环；底盘：速度环 + 2.4 运动学分解。
  • 环数不是越多越好：每多一层，就多一组要整定的参数、多一份延迟，够用就好。
  • 各执行器具体用哪些环，讲解时结合战队现有代码展示。

各执行器调参方向（只讲方向，不给数值）

执行器物理特点调参方向与理由
云台 Pitch重力始终往下拽足够的 I 或重力补偿扛住重力，否则垂头、回中慢
云台 Yaw摩擦大、有静摩擦适当 I 克服静摩擦；I 太大低频抖动
底盘惯性大、整车重P 不宜过大，否则来回冲；以速度环为主
摩擦轮只求转速稳、响应快转速环为主，往快响应调，波动小即达标
每台车重心、摩擦都不同：方向照此表，数值必须实车整定。
Pitch 受重力 → 重 I / 重力补偿；Yaw 摩擦大 → 重 I；底盘惯性大 → 轻 P；摩擦轮 → 快响应。

整定顺序五步

  1. 确认传感器正常：陀螺仪零漂、编码器方向，再动手调参。
  2. 串级先内环后外环：内环（速度环）调稳了，外环才有的调。
  3. 先 P：让系统大致跟上目标、不振荡。
  4. 再 D 压超调，最后加 I 消静差。
  5. 确认限幅与抗饱和都已生效，再上剧烈目标测试。
两条铁律：先内后外；先 P、后 I、再 D。顺序反了越调越乱。

进阶 PID 代码骨架（一）：结构体与初始化

/* 进阶 PID：输出限幅 + 积分限幅 + 抗饱和 + 微分滤波 */
typedef struct {
    float kp, ki, kd;        /* PID 增益 */
    float out_max;           /* 输出限幅值：按电机最大电流/电压设 */
    float int_max;           /* 积分限幅值：积分最多攒这么多 */
    float filt_coef;         /* 微分低通滤波系数 0~1，越小滤波越重 */
    float err_sum;           /* 积分累积量 */
    float prev_err;          /* 上一次误差（微分用） */
    float prev_filt;         /* 上一次滤波后误差 */
} PidAdv;

static float clampf(float v, float lo, float hi)
{ return v < lo ? lo : (v > hi ? hi : v); }
四道护栏全部封装在结构体里；初始化时按电机手册设定 out_max，滤波系数与增益实车整定。

进阶 PID 代码骨架（二）：更新函数

/* 每个控制周期调用一次（如 1kHz），dt 为周期秒数 */
float pid_adv_update(PidAdv *p, float target, float measure, float dt) {
    float err = target - measure;
    /* ① 微分：误差先一阶低通滤波再差分，滤掉编码器毛刺 */
    float filt_err = p->prev_filt + p->filt_coef * (err - p->prev_filt);
    float d_term = p->kd * (filt_err - p->prev_filt) / dt;
    p->err_sum += p->ki * err * dt;                  /* ② 积分累积 */
    float out = p->kp * err + p->err_sum + d_term;
    float out_lim = clampf(out, -p->out_max, p->out_max); /* ③ 输出限幅 */
    /* ④ 抗饱和：输出被限幅压住时反算积分；⑤ 积分限幅 */
    if (out != out_lim) p->err_sum = out_lim - (p->kp * err + d_term);
    p->err_sum = clampf(p->err_sum, -p->int_max, p->int_max);
    p->prev_err = err; p->prev_filt = filt_err;
    return out_lim;
}
五处保护依次生效：①微分滤波 ②积分累积 ③输出限幅 ④抗饱和（反计算）⑤积分限幅。

串级 + 前馈：调用骨架

/* 串级：外环输出 = 内环目标（云台 Pitch 示例） */
float w_ref = pid_adv_update(&pos_loop, ang_ref, ang_cur, dt);
float u_fb  = pid_adv_update(&vel_loop, w_ref, vel_cur, dt);

/* 前馈：按目标直接给，不等误差 */
float u_ff = ff.kv * w_ref                          /* 速度前馈 */
           + ff.grav * cosf(ang_cur * DEG2RAD);     /* 重力补偿 */

motor_set_current(PITCH_MOTOR, u_fb + u_ff);      /* FB 纠错 + FF 给大头 */
完整版（含加速度前馈、摩擦补偿、结构体定义）见 教学内容.md 任务一至任务三。
整定顺序：先内环后外环；前馈系数最后单独调；目标有阶跃时先做平滑轨迹，前馈才不会打出尖峰。

进阶 PID 仿真器：三个开关都试一遍

前馈（Feedforward, FF）：提前给，不等误差

反馈 Feedback前馈 Feedforward
依据误差 e = 目标 − 实际目标信号本身（参考轨迹）
特点错了再改，天生滞后半拍提前给够，无滞后；依赖模型与系数
短板误差为零时输出约零（只剩 I）系数不准会过冲或欠补
四种前馈形式解决什么问题
速度前馈kv · ω_ref跟踪运动目标慢半拍
加速度前馈ka · α_ref惯性大的负载加速时跟不上
重力补偿k_g · cosθPitch 不同仰角所需力矩不同
摩擦补偿F_fric · sign(ω_ref)克服静摩擦「第一下」
u = u_fb + u_ff：反馈负责纠错，前馈负责给大头——队友，不是对手。

速度前馈与加速度前馈

速度前馈（Velocity FF）

u_ff = kv · ω_ref：目标角速度乘系数直接加到输出。目标动得越快、提前给得越多，解决跟踪运动目标慢半拍。

整定：kv 从小到大，跟随误差最小为佳；给过大引起超调。

加速度前馈（Acceleration FF）

u_ff = ka · α_ref：目标加速度乘系数。惯性大的负载（云台带动大质量）加速时需额外力矩。

α_ref 来自轨迹规划的微分；平缓轨迹下此项常可省去。

目标若是阶跃（突变），速度 / 加速度前馈会在瞬间打出尖峰——目标先做平滑（斜坡、S 形轨迹）再用前馈。

重力补偿与摩擦补偿

重力补偿（Gravity Comp.）

Pitch 停在仰角 θ 所需维持力矩：τ_g = m·g·L·cosθ（水平最大、竖直为零）。

补偿项 u = k_g · cosθ，按当前角度即时补上；第 19 页演示可拖动角度观察。

摩擦补偿（Friction Comp.）

静摩擦是起步「第一下」卡顿的主因：u = F_fric · sign(ω_ref)，补一个恰好克服静摩擦的固定量，方向随目标速度方向。

F_fric 按实测静摩擦力矩设定，不宜过大。

I 项也能扛重力与静差，但靠误差慢慢攒，慢；前馈按角度 / 方向即时给上，两者常并用。

前馈对比：同一目标，三种方案

同一目标（斜坡转到 30°）：仅反馈 / +速度前馈 / +前馈+重力补偿；切开关后点重播

重力补偿示意：力矩随角度变

重力力矩 = m·g·L·cosθ：抬得越高，力矩越小，补偿量越小

常见问题与排查

现象可能原因排查方法
云台到限位附近猛抽堵转时积分攒爆（饱和）检查抗饱和生效；给积分限幅
云台高频抖动、电流声微分用了带噪声的位置差分微分加低通滤波，或用陀螺仪
大跳变目标超调严重限幅后积分继续累积开启饱和时停止 / 回退积分
串级越调越乱先调了外环固定外环输出，先把内环调好
跟踪快速目标慢半拍只有反馈、没有前馈加速度 / 速度前馈
特定角度停不住、缓滑重力力矩没被补偿增大 I 或加重力补偿

四个高频坑

1. 先调外环

串级先调外环 → 越调越乱。先内后外。

2. 没加限幅

输出飙到极限 → 电机猛抽、发热。

3. D 用原始差分

毛刺被放大 → 云台抽搐。先滤波。

4. 前馈系数乱拍

给多过冲、给少没用 → 实车整定。

记住两句话：限幅是保护，抗饱和是让积分别捣乱；调参按「先内后外、先 P 后 I 再 D」。
