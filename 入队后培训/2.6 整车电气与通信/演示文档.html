CAN 总线：定义与特性

CAN（Controller Area Network，控制器局域网）是 ISO 11898 标准的多主串行总线：所有节点共享一对差分线 CAN_H / CAN_L，以报文广播方式通信。RoboMaster 常用速率 1 Mbps，线缆为 120Ω 特性阻抗双绞线。

特性说明
多主广播无主机概念，任意节点可发，所有节点可收
差分抗干扰用两根线电压差表示 0/1，共模干扰被抵消
硬件检错CRC 校验、ACK 确认、错误帧，出错自动重发
非破坏仲裁同时发送时 ID 小者优先，数据不被破坏

拓扑与差分信号

电平状态CAN_HCAN_L压差
显性（逻辑 0）约 3.5 V约 1.5 V约 2 V
隐性（逻辑 1）约 2.5 V约 2.5 V约 0 V

干扰通常同时抬升/拉低两线，压差几乎不变；双绞线让两线受扰更一致。电平为 ISO 11898-2 典型值，以收发器手册为准。

标准帧结构：固定格式的报文

字段位宽作用
SOF 帧起始1一个显性位，宣布开始发送
仲裁 ID11标识符：地址＋优先级（标准帧）
RTR1区分数据帧/远程帧，数据帧为显性 0
DLC4数据长度码，表示数据段 0~8 字节
数据段0~64有效载荷，各字节含义由上层协议定义
CRC15校验码，收方重算比对，不一致即传错
ACK1发方发隐性 1，收方回显性 0 覆盖，表示收到
EOF77 个隐性位，宣布帧结束

教学简化：省略 IDE 位、保留位与界定符，完整定义见 ISO 11898。位填充：连续 5 个相同位后插入反位，硬件自动完成。

CAN ID：地址与仲裁

ID 的两个作用

  • 地址：只收发给自己的报文（标准帧 11 位，0~2047）
  • 优先级：ID 越小越先发送

仲裁规则

  • 线与结构：显性 0 压过隐性 1
  • 逐位比较，先出现 0 者胜，败者退让重发
例：0x200 与 0x201 同时发送，前 10 位相同，第 11 位 0 胜出。整车应用：反馈帧 ID＝0x200＋电调 ID，主控据此识别来源（以官方手册为准）。

波特率：全员统一的语速

波特率＝每秒传输的位数（bit/s）。总线上所有设备必须一致，否则收方解出乱码；RoboMaster 常用 1 Mbps。一个位由若干时间份额 TQ 组成，具体配置以单片机手册与官方例程为准。

检查项说明
不匹配现象收到乱帧、错误帧，或完全收不到数据
排查方法核对全车设备波特率配置；示波器测位宽验证实际速率

终端电阻：总线两端的 120Ω

信号到达导线末端会反射，与后续信号叠加成毛刺。解法：总线物理两端各接 1 个 120Ω，匹配线缆特性阻抗、吸收反射。只有两端各一个，不是每个节点都加。

断电测量 CAN_H-CAN_L含义
约 60Ω正常（两个 120Ω 并联）
约 120Ω少一个终端电阻
接近 0Ω两线短路
开路总线断线

类比：水管两端装堵头，防止回波。

电机与主控通信：ID 规律

报文ID 规律方向
控制帧0x200（全体）或 0x1FF / 0x2FF（分组）主控 → 电调
反馈帧0x200 + 电调ID（1 号 → 0x201）电调 → 主控
字段含义与分组方式以官方手册为准。
板间通信同样三步对齐：波特率 → ID → 帧格式。

整车电气＝一棵电源树

常电

主控、裁判系统、IMU 等逻辑电路；电流小，必须干净稳定。

动力电

电调 → 电机、发射机构；电流大（可达数十安培），波动大。

第一原则：强电弱电分家；布线按动力 / 常电 / 信号 / 射频分层，动力线与信号线避免长距离并行。

电池与电源管理模块

电池是全车能量源头，最怕过放与短路；上电前先查电压与插头（型号以战队实际为准）。电源管理模块（PM）是车上的「总电表＋总闸」。

PM 官方参数（以官方手册为准）数值
供电输入DC 24 V
动力输出3 路 24 V：底盘 10 A / 云台 10 A / 发射机构 8 A，合计 20 A
常电输出5 V / 12 V / 24 V，供裁判系统各模块
用户串口向主控输出裁判系统信息（血量、状态等）
通断控制可按裁判系统服务器指令对输出断电

超级电容：动力电上的功率缓冲

  • 定义：并接在动力电总线上的储能元件，做功率缓冲
  • 工作方式：平时充电；电机瞬时大电流时先由电容放电补充，削平电压跌落与尖峰
  • 类比：水库平时蓄水，高峰用水时先放水补充
  • 效果：减轻电池压降，改善急加速表现，降低主控被拖垮的风险
  • 容量与接入位置以战队实际方案为准

电调与主控：整车角色

电调（ESC）

  • 与电机一对一配套（M3508↔C620、M2006↔C610）
  • 挂 CAN 收指令，输出三相动力电
  • 动力线粗短、注意散热通风
  • 过流/堵转/温度告警必须接入主控逻辑

主控（开发板 C 型）

  • 输入 8~28 V，挂常电支路
  • 板载 IMU；2 路 CAN；UART、DBUS、USB
  • 经 CAN 发指令收反馈，经串口接裁判系统
  • 完整参数以官方手册为准

接插件、线材与接地

接插件与线材

  • 动力电用大电流插接件（如 XT30 / XT60，以战队实际为准），防松、防反接
  • 插头必须插到位——松动插头是整车故障第一来源
  • AWG 号越小线越粗；大电流走粗线，防发热与压降
  • CAN 线用双绞线
接地铁律做法原因
一点接地各地线汇集公共点防地电位漂移
必须共地设备间地线相连信号有参考基准
粗细匹配地线与正极同粗防压降与串扰

电磁干扰：来源与对策

最大干扰源：电调PWM 大电流开关；其次为发射机构、继电器等开关器件。受害者：图传（雪花）、传感器与通信（数据乱跳）、常电（主控复位、ADC 漂移）。

对策做法原理
远离图传天线、信号线远离动力线与大电流器件干扰随距离快速衰减
屏蔽信号线用屏蔽线，屏蔽层一端接地金属网挡住辐射
双绞差分信号用双绞线两线受扰一致，相减抵消
滤波电源入口加电容吸平电源毛刺

症状排查修复
全车无反应，主控不亮量电池电压；查总开关/保险与输入接口充电换电池；换保险；重插输入

症状排查修复
