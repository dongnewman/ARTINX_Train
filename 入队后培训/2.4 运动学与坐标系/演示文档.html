三种坐标系：以谁为基准说话

坐标系基准与定义谁在用
世界坐标系 World场地固定不动，如俯视地图视觉、裁判系统、导航
机器人坐标系 Robot原点在车体，X 轴 = 车头方向底盘控制、IMU 输出
云台坐标系 Gimbal原点在云台，X 轴 = 炮口方向云台控制、射击
同一个矢量在不同系里坐标不同：车转 30°，世界系里的敌人坐标不变，机器人系里的坐标就跟着变。类比：地图、车上的人、云台上的人，都能指到同一个目标，但「前、左、右」含义不同。

坐标变换：2×2 旋转矩阵

机器人系 → 世界系：
[ x_w ]   [ cosθ  −sinθ ] [ x_r ]
[ y_w ] = [ sinθ   cosθ ] [ y_r ]
θ = 车头相对世界系 X 轴的夹角，逆时针为正

手算验证

θ = 90°：车头 (1,0) → 世界系 (0,1)；车正前方 2 m 的点 (2,0) → (0,2)。

用途

视觉给出世界系目标，经旋转矩阵转进机器人系、云台系，才能算出瞄准角。

比赛还约定场地坐标系（红方/蓝方视角），原理相同，仅零点和方向定义不同；矩阵就是「把机器人系的地图转 θ 度对齐到世界系」。

演示一：坐标系关系（拖动滑块）

观察「车→目标」矢量在三套系中的坐标读数

Yaw / Pitch / Roll：三个姿态角

Yaw 偏航

车头左右摆：原地转、小陀螺

Pitch 俯仰

炮口抬高 / 压低（点头）

Roll 翻滚

车体左右倾斜（侧翻）

右手定则：右手握轴、拇指指向轴正方向，四指弯曲方向为正。IMU（惯性测量单元）实时输出这三个角，是云台「反向补偿」的数据来源。

麦轮单轮：45° 辊子的作用

定义：轮毂外圈斜 45° 装一圈小辊子（roller），辊子可绕自身轴自由转动。
轮子正转时摩擦被辊子「掰」成斜 45° 力，分解为前进分量 + 侧移分量——横移力量的来源。
沿辊子方向的分量被辊子空转「吃掉」，不传给车身。
45° 是关键：0° 是普通轮只有前后力；90° 是全向轮只有左右力；45° 两边各占一半。

演示四：单轮受力分解

正转：合力斜前 45°；反转：整体反向

四轮组合：核心是「抵消」

前进：四轮同向同速，左右分力两两抵消

横移：对角同转、邻轮反向，前后分力抵消

旋转：左轮反转、右轮正转，只剩力矩原地转

斜移 = 前进 + 横移按比例叠加。要前进就抵消左右分量，要横移就抵消前后分量，要旋转就抵消平动分量。

麦轮布置与符号约定

X 型与 O 型布置

X 型（对角同型）：左前 = 右后为 A 型、右前 = 左后为 B 型；O 型（左右同型）公式符号图案不同。全队必须统一一种并写进注释，混装会出现「横移变斜线」。

本节统一约定

机器人系 X 前、Y 左、Z 上（右手系）；ω 正 = 俯视逆时针（左转）；a、b = 轮子到车中心的纵向、横向距离，旋转项系数为 (a+b)。

演示与代码全部采用本页约定；讲解时结合战队现有代码对照符号。

麦轮解算：目标速度 → 四个轮速

V1(左前) = Vx − Vy − ω·(a+b)
V2(右前) = Vx + Vy + ω·(a+b)
V3(左后) = Vx + Vy − ω·(a+b)
V4(右后) = Vx − Vy + ω·(a+b)
  • 平移项：Vx 四轮全同号；Vy 左前/右后为负、右前/左后为正（对角同号、邻轮异号）
  • 旋转项：右前/右后为正、左前/左后为负，车向左转
  • 严格推导多一个 √2 系数（45° 分解代价），工程上作整体比例，由速度环 PID 补偿
速度溢出：前进 + 横移 + 旋转同时拉满时某轮速可达上限 2 倍。处理：四个轮速等比例缩小（方向比例不变，轨迹不变形）。

解算代码骨架（C 语言）

/* 约定：X 前、Y 左、ω 逆时针为正；1=左前 2=右前 3=左后 4=右后 */
typedef struct { float vx, vy, vw; } ChassisVel;      /* 目标速度 */
typedef struct { float w1, w2, w3, w4; } WheelSpd;     /* 四轮速 */

WheelSpd mecanum_solve(ChassisVel v, float a, float b)
{
    WheelSpd w;
    float k = a + b;                 /* 旋转项公共系数 */
    w.w1 = v.vx - v.vy - v.vw * k;   /* 左前 */
    w.w2 = v.vx + v.vy + v.vw * k;   /* 右前 */
    w.w3 = v.vx + v.vy - v.vw * k;   /* 左后 */
    w.w4 = v.vx - v.vy + v.vw * k;   /* 右后 */
    return w;
}
/* 限幅：任一超限则四个等比例缩小 */
不用背公式——平移看「对角同号」图案，旋转看「右正左负」。完整可编译代码见教学内容.md 任务二。

另两种全向方案：全向轮与舵轮

麦克纳姆轮全向轮 Omni舵轮 Steering
结构轮毂 + 45° 斜辊子轮毂 + 90° 竖辊子普通轮 + 转向电机
安装四轮平行，如普通车3~4 轮按角度斜装四轮各带转向机构
横移支持，任意方向支持，任意方向支持，但先转轮、有延迟
优点装车简单，赛场主流结构简单、侧向力大抓地好、负载大、越障强
缺点辊子交替接地略颠、怕滑接地不连续、震动大结构复杂、控制最麻烦
解算线性公式（本节）类似向量分解转向角需反三角函数
步兵 / 英雄用麦轮；工程取弹小车常用舵轮（负载重、需精确对准）。舵轮转向角还需满足各轮转向圆共圆心的几何约束。

云台角度：相对角与绝对角

相对角

云台相对车体转的角度；由云台 Yaw / Pitch 电机编码器测量；上电归零，掉电即忘。

绝对角

云台相对场地的指向；编码器 + 底盘 IMU Yaw 合成；车怎么转，炮口指向不受影响。

绝对角 = 相对角 + 底盘Yaw　例：底盘 Yaw = +30°，云台要指正前方（0°），相对角应打到 −30°，即「反向补偿」。多圈编码器：累计圈数，超过一圈不丢角度

云台控制：位置环与速度环

位置控制

目标：转到某个角度（°）；反馈：编码器角度。用于云台瞄准、舵轮转向角。

速度控制

目标：保持角速度（°/s）；反馈：角度差分。用于底盘轮速、云台跟随时。

串级结构：位置环（外环）输出目标角速度，速度环（内环）执行——「想去 30°，先算出该用多快冲过去，快到再减速」；2.5 节展开。底盘通常只跑速度环：摇杆给出的就是速度指令。

视觉目标到云台角度：完整链路

  1. 视觉在世界系给出敌人方位角 target_world（相对场地）
  2. 减底盘 Yaw（IMU）→ 得到敌人相对车头的角度
  3. 减云台当前相对角 → 得到云台还差多少度
  4. 位置环输出目标角速度，速度环执行
  5. 每一步用回绕函数包到 (−180°, 180°]，防止跨圈跳变
float wrap180(float d){ while(d>180)d-=360; while(d<=-180)d+=360; return d; }
float rel = wrap180(target_world - chassis_yaw);   /* 世界目标 → 云台相对角 */

常见问题与排查

现象可能原因排查方法
横移走成斜线 / 原地转圈某轮装反（A/B 型装错）或公式符号反纸笔推符号；单独给 Vy 看是否纯横移
原地旋转时车会漂移轮径不一致、摩擦不同、系数不统一空转校准轮径；查限幅后比例
满速前进时轨迹变形速度溢出没限幅检查每周期是否调等比例限幅
云台上电自转 / 乱甩零位没初始化、补偿符号反上电标零；核对「绝对角 = 相对角 + 底盘Yaw」符号
云台角度转到一圈时跳变编码器单圈回绕没处理用 wrap180 统一回绕到 (−180°, 180°]
麦轮在滑场地上走不直辊子打滑，开环速度控制兜不住加底盘 IMU 反馈（调车章节展开）
