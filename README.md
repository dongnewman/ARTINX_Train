# ARTINX_Train

RoboMaster 机甲大师机器人大赛南方科技大学 ARTINX 战队电控组培训资料。

## 培训目标

电控组的核心不是单纯写代码，而是把机械、视觉和整车控制统一起来，做到需求清晰、系统稳定、问题可定位、车辆可长期可靠运行。

## 培训安排

### 1. 入队前培训

面向新成员，重点建立基础认知和动手能力。

- 环境配置：VS Code、MSYS2、GCC、Python、STM32CubeMX、Keil、ST-Link、Git
- C 语言入门：变量、分支、循环、函数、数组、结构体、指针、头文件
- 单片机基础：GPIO、Timer、PWM、UART、CAN、中断、DMA
- 电机与控制：电机反馈、速度闭环、PID 初步理解
- 工具使用：Git 与 AI 辅助开发
- 综合作业：完成一个小型控制任务，检验独立开发与调试能力

### 2. 入队后培训

面向正式成员，重点建立完整整车开发能力。

- 规则研读与需求分析
- 裁判系统与整车设备认识
- 软件架构与模块协作
- PID、前馈与运动学基础
- 整车电气、联调与调试
- 稳定性、可靠性与赛场问题处理

### 3. 长期学习

针对具体方向持续维护专题文档，服务新车开发、版本迭代和赛场调试。
