# ARTINX_Train

RoboMaster 机甲大师机器人大赛南方科技大学 ARTINX 战队电控组培训资料（2027 赛季）。

## 培训目标

电控组的核心不是单纯写代码，而是把机械、视觉和整车控制统一起来，做到需求清晰、系统稳定、问题可定位、车辆可长期可靠运行。

## 资料使用说明

每个小节一个文件夹，内含两个文件：

| 文件 | 用途 |
|---|---|
| `教学内容.md` | 详细讲义：概念讲解 + 动手实践 + 常见问题 + 课后自测（含答案）+ 延伸资源，适合课堂学习与课后自学 |
| `演示文档.html` | 授课幻灯片：双击用浏览器打开即可放映，键盘 ← → 翻页、F 全屏、? 帮助；含大量可交互演示（拖动滑块、点击卡片等） |

幻灯片风格参照队内 PPT 模板：暗色封面（黑底紫光 + 荧光绿）+ 白底内容页，品牌紫 `#784CF6` / 荧光绿 `#AFFF00`，内嵌队徽，完全离线可用；所有外链均已人工验证真实存在。
