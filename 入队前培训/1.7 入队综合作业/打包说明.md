# 离线包说明

本目录提供两个教学用离线包：

- `ARTINX_战队代码框架_去Git.zip`：当前战队框架工作区的文件快照。
- `ARTINX_RTT工具_去Git.zip`：当前战队 RTT 监视与调试工具的文件快照。

## 已移除内容

打包时移除了 `.git`、`.gitignore`、`.gitattributes`、`.gitmodules`、`.github` 等 Git 元数据与配置；同时移除了 Keil 编译产物、Python 缓存、历史日志和编辑器个人配置。压缩包不携带提交历史、远端地址、分支或用户凭据。

## 快照边界

两个源目录在打包时都不是干净工作区，因此压缩包代表“打包时磁盘上可见的当前文件”，不是某个 Git 提交的可复现导出。教学作业只要求在此快照上完成代码与实验，不要求使用 Git。

不要把压缩包中的旧 `.axf`、`.hex` 或 `.map` 当成当前固件证据；这些生成物已从框架包移除。首次使用时应在自己的 Keil 环境重新编译，并确认 `0 Error(s)`。

## RTT 调参提示

RTT 工具的在线参数修改功能可能通过调试器直接写目标内存，而不是 RTT 下行通道。参数地址必须来自与当前固件完全匹配的 ELF/MAP；每次写入后应由固件回传参数值进行确认。详见 `RTT调参与数据提交指南.md`。

## 完整性

最终 SHA-256 值记录在同目录 `SHA256SUMS.txt`。解压前可先校验哈希，避免传输或拷贝损坏。
