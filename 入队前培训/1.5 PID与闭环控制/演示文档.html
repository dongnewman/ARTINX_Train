1.5　PID 与闭环控制

PID 与闭环控制

从「我发多少电流」到「我告诉它跑多快」——第一次把反馈接进控制回路
电控组长 董心宇

本节地图

概念

开环与闭环；Target / Current / Error；P / I / D 定义与作用

演示

PID 实时仿真器（四种预设）；误差动画；开环与闭环扰动对比

实践

电机速度闭环；改目标速度；调参数、读响应曲线

开环控制 与 闭环控制

开环（Open-Loop）

指令直接驱动电机，输出不参与计算；条件一变，转速漂了没人管。

闭环（Closed-Loop）/ 反馈（Feedback）

测量输出，与目标比较得误差，按误差修正输入，形成回路。

开环闭环
依据只信指令指令 + 实测
抗扰动差，漂了没人管好，自动纠偏
成本低需要传感器与算法

类比：蒙眼开车 vs 睁眼开车——闭环多了「看路」这一步。

演示：开环 vs 闭环（同一扰动）

同一电机模型、同一目标阶跃：开环按标定值发 600，闭环由 PID 自动纠偏。点「扰动」看谁被打偏。

闭环五件套：Target / Current / Error / Output

Target 目标值

期望输出（目标转速 1000 RPM）

Current 当前值

传感器测得的实际输出（编码器转速）

Error 误差

Target − Current，正负定方向

Output 输出

控制器算出的控制量（电调电流）

速度环数据流（衔接 1.4）

Target 目标转速 → ⊕ 比较 ← 编码器转速 Error → PID → Output 电流 → CAN / 电调 → 电机 → 转速

1.4 的「读反馈」与「发控制量」不变，中间只多一步 PID 计算。

控制 = 不断「测差距、消差距」。误差为正则加大输出，为负则减小输出。

演示：误差动画（洗澡调水温）

绿虚线 = Target，紫线 = Current，阴影 = Error。类比：目标=想要的水温，当前=手摸到的水温，误差=差多少，输出=阀门拧多大。点「冷水冲击」观察误差如何被消掉。

P —— 比例（Proportional）

u_P = Kp × e(t)：输出与误差成正比，误差越大输出越大；e = 0 时输出为 0。
  • 类比一句话：水太凉就多开热水，差越多拧越大。
  • 特性：立即响应、无滞后；Kp 越大越有力。
  • 代价：Kp 过大 → 超调、震荡、啸叫。
只有 P 会「差一截」，原因与数字示例见下页。

为什么只有 P 会「差一截」

维持转速需要持续电流，P 的输出却随误差归零——只能停在「差一点」的平衡点。

维持 1000 RPM 需 600 电流： Kp = 2 → e = 300 → 停在 700 RPM Kp = 10 → e = 60 → 停在 940 RPM

Kp 越大「差」越小，但永远消不掉——该残余偏差即稳态误差（Steady-State Error），由 I 负责消灭。

I —— 积分（Integral）

u_I = Ki × ∫ e dt：输出与误差对时间的累计成正比，误差存在越久，积分项越大。
  • 类比一句话：一直差一点，就再拧一点。
  • 作用：消除稳态误差；误差归零后，积分项保留为维持输出所需的值。
风险：积分饱和（Integral Windup），过冲后难以收回。见下页。

积分饱和（Integral Windup）

  • 误差长期不归零 → 积分累计过大 → 过冲后回不来。
  • 大阶跃 + 大 Ki：输出顶格、冲过目标、慢慢爬回。
演示「积分饱和」预设可复现；防线：积分限幅 i_max，2.5 展开进阶方案。

D —— 微分（Derivative）

u_D = Kd × de/dt：输出与误差变化率成正比，误差收敛越快，「刹车」越强。
  • 类比一句话：快到了，提前收手。
  • 作用：预测趋势、抑制超调，等效给系统加阻尼。
  • 风险：放大测量噪声（编码器抖动被微分放大），低速明显；能不加就不加。

PID 完整形式与参数效果

u(t) = Kp·e(t) + Ki·∫ e(τ) dτ + Kd·de(t)/dt　　（现在 · 过去 · 未来）
调大响应速度超调稳态误差主要副作用
Kp变快可能增大减小但消不掉过大 → 震荡、啸叫
Ki略快增大消除积分饱和
Kd提前量减小几乎无影响放大噪声

这张表 + 调参顺序，是本节唯一要求记住的内容。

演示：PID 实时仿真器

模型 = 两级惯性电机 + 48 ms 测量延迟；离散 PID（dt = 0.004 s），含输出限幅与积分限幅。预设：稳定 / 超调 / 震荡 / 积分饱和。

调参顺序（新手照做）

1　只留 P：从 0 起步，×1.5 加，直到跟得上
2　加 I：慢慢加，直到稳态误差 < 2%
3　冲过头？加一点 D，能不加就不加
4　一次只改一个参数，观察后再动

连续 PID → 离散 PID

连续形式

u(t) = Kp·e(t) + Ki·∫e dt + Kd·de/dt

离散形式（周期 dt 固定）

u_k = Kp·e_k + Ki·Σ(e_i·dt) + Kd·(e_k − e_(k−1))/dt

  • 积分 → 累加：每周期把 Ki·e·dt 累进积分项。
  • 微分 → 差分：本次误差减上次误差，再除以 dt。
  • 限幅：积分限幅 i_max 与输出限幅 out_max 都不可省。

离散 PID 代码（C）

float PID_Calc(PID_t *pid, float target, float current, float dt)
{
    float e = target - current;                /* 误差 */
    float p = pid->kp * e;                     /* P：比例 */
    pid->i_term += pid->ki * e * dt;          /* I：积分累加 */
    if (pid->i_term >  pid->i_max) pid->i_term =  pid->i_max;   /* 积分限幅 */
    if (pid->i_term < -pid->i_max) pid->i_term = -pid->i_max;
    float d = pid->kd * (e - pid->last_e) / dt;  /* D：微分差分 */
    pid->last_e = e;
    float out = p + pid->i_term + d;           /* 三项求和 */
    if (out >  pid->out_max) out =  pid->out_max;             /* 输出限幅 */
    if (out < -pid->out_max) out = -pid->out_max;
    return out;
}

调用位置：定时器中断 / 周期任务（如 1 kHz，dt = 0.001f）。真机常用「D 作用于测量值」避开目标跳变冲击，2.5 展开。

两个「以后细学」的点

dt 固定（控制周期）

参数与 dt 配套；PID 放定时器中断，不裸跑 while(1)。

积分限幅（i_max）

抗积分饱和的第一道防线。

2.5 展开：抗饱和、微分滤波、串级 PID、前馈。

实践：电机速度闭环（45 分钟）

  1. 加 pid.c / pid.h，编译 0 报错 0 警告
  2. 1 ms 中断：读转速 → 算误差 → PID → 发电流
  3. 只调 P：跟得上、差一截
  4. 加 I：稳态误差 < 2%
  5. 阶跃 0→1000→2000→0 看响应

怎么读响应曲线（+ 加分项）

  • 上升时间、超调量、稳态误差、震荡次数
  • 口诀：慢加 P、差加 I、冲加 D、抖减增益
  • 加分：串口 + Python 画曲线对比仿真
  • 安全：电机固定、目标从小到大、异常断电
