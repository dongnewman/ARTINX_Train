C 程序长什么样，怎么跑起来

程序结构

  • C 程序由函数组成；main 是唯一入口，程序从这里开始执行
  • 语句以分号 ; 结尾，花括号 { } 组成语句块
  • 注释不参与编译：// 行注释、/* */ 块注释
  • 类比一句话：main 是信的正文起点，分号是句号

编译与运行（终端）

# 编译：把 .c 源码翻译成可执行文件
gcc hello.c -o hello

# 运行
./hello

流程：编写 .c 源码 → gcc 编译 → 运行可执行文件

Hello World：第一个程序

/* hello.c */
#include <stdio.h>  // 标准输入输出库

int main(void)
{
    printf("Hello, ARTINX!\n");
    return 0;
}
代码作用
#include <stdio.h>引入标准输入输出库，才能用 printf
int main(void)程序入口，从这里开始执行
printf(...)打印一行，\n 是换行符
return 0;正常结束，把 0 交还操作系统

变量：可读写的命名存储单元

定义与三步走

  • 变量（variable）：程序运行时可读写的命名存储单元，类型决定其宽度与取值范围
  • 声明 = 买盒子贴标签，赋值 = 放东西（类比）
  • 命名：字母 / 数字 / 下划线，不能以数字开头；建议见名知意，如 motor_speed
  • 初始化：声明同时赋值，int speed = 3000;
int  speed = 3000;    // 整数
char team  = 'A';      // 单个字符
float ratio = 0.5f;    // 单精度小数

speed = 2500;          // 重新赋值
printf("%d %c %.2f", speed, team, ratio);

printf 是填空题：%d 整数、%c 字符、%f 小数、%.2f 保留两位

数据类型与取值范围

类型宽度取值范围（常见实现）装什么占位符
char1 字节−128 ~ 127（有符号）字符或小整数%c
int4 字节−2147483648 ~ 2147483647整数（最常用）%d
float4 字节约 ±3.4e38，6~7 位有效数字小数（单精度）%f

溢出：写入超出取值范围的值会回绕（int 最大值 +1 变最小值）

截断：小数赋给 int，小数部分直接丢弃：int a = 3.9; 得 3

嵌入式常用固定宽度类型：uint8_t / int16_t / int32_t（#include <stdint.h>），宽度不随平台变化，后续写单片机代码常用

演示：把数字放进盒子（类型决定盒子大小）

点击上方盒子可切换类型

运算符与优先级

算术

+ − * / %（取余）
整数除法截断：5 / 2 == 2
5 % 2 == 1

关系

==　!=　>　<　>=　<=
结果为 0（假）或 1（真）

逻辑

&& 与　|| 或　! 非
0 < x && x < 10：x 在开区间 (0,10)

优先级要点

乘除高于加减，比较高于逻辑与或；拿不准一律加括号

头号坑：= 是赋值，== 才是相等判断。if (x = 0) 恒为假，还改掉了 x 的值

分支一：if / else

if (条件)          // 0 为假，非 0 为真
    语句 1;
else if (条件 2)
    语句 2;
else
    语句 3;

多分支用 if - else if - else 级联；只有一条语句时花括号可省，但建议始终写 { }

例：成绩评级

if (score >= 90)      printf("A");
else if (score >= 80) printf("B");
else if (score >= 70) printf("C");
else if (score >= 60) printf("D");
else                  printf("F");

条件从上到下依次判断，命中即执行并结束整个 if

分支二：switch / case

switch (level) {
case 1:  printf("低速"); break;
case 2:  printf("中速"); break;
case 3:  printf("高速"); break;
default: printf("未知");
}

使用要点

  • case 后只能是整型常量（数字、字符、枚举值），不能写范围
  • 每个 case 结尾写 break，否则「贯穿」继续执行下一分支
  • default 兜底所有未匹配情况
  • 适用场景：档位、状态机、按键值等多选一

循环一：for（知道圈数）

// ① 初始　② 条件　④ 每圈更新
for (int i = 1; i <= 100; i++)
{
    sum = sum + i;   // ③ 循环体
}

执行顺序：① → ② → ③ → ④ → ② → ③ → …，直到条件为假

三要素

  • 初始化：从哪开始（只执行一次）
  • 条件：到哪结束（每圈先检查）
  • 更新：每圈结束怎么变（i++ 即 i = i + 1）

复合赋值

sum += i 等价 sum = sum + i；i++ 等价 i = i + 1

循环二：while / break / continue

while (i <= 100)      // 条件成立就继续转
{
    sum = sum + i;
    i++;
}
  • while 适合不知道圈数、靠条件退出
  • break：跳出整个循环；continue：跳过本轮，进入下一圈

单片机的主循环

while (1) {
    读传感器;
    计算控制量;
    驱动电机;
}

while (1) 是死循环：上电后永远重复执行，后续每一节都会见到

演示：for 循环 1 加到 100（速度可调）

答案：1 + 2 + … + 100 = 5050

函数：输入参数，输出返回值

// 定义：返回类型 函数名(参数列表)
int max2(int a, int b)
{
    if (a > b) return a;
    return b;      // return 结束函数
}

调用：max2(3, 7) 得 7；函数可以再调用函数（max3 内部用 max2）

函数原型（声明）

int max2(int a, int b);   // 只有签名，没有函数体
  • 原型只写签名加分号；实现写在 .c，原型放进 .h 供他人调用
  • 默认传值：参数是副本，函数内修改不影响原变量（传址见指针一节）
  • 不返回值的函数用 void：void set_speed(int v);

数组：连续存储，下标从 0 开始

int arr[5] = {10, 20, 30, 40, 50};

arr[2] = 99;              // 改 2 号元素

for (int i = 0; i < 5; i++)   // 遍历
    total += arr[i];

要点

  • 定义：同类型元素的连续存储区，元素个数在编译时确定
  • 下标范围 0 ~ n−1，第一个元素是 arr[0]
  • 初始化未写满自动补 0：int a[5] = {1,2,3};
  • 访问 arr[5] 是越界——未定义行为：可能乱值、崩溃，或碰巧正常

struct 打包数据，enum 限定选项

struct 结构体

struct Student {
    char  name[16];
    int   id;
    float score;
};
s1.id = 20260101;    // . 访问成员

把不同类型字段打包成一个整体；电机的电流 / 转速 / 角度 / 温度可打包成一个结构体（讲解时结合战队现有代码展示）

enum 枚举

enum Mode { STOP, FOLLOW, TRACK };
// 默认编号 0,1,2，可手动指定
enum Mode m = FOLLOW;

把变量限定在固定选项内，替代魔法数字 0/1/2，可读性更好

指针：保存地址的变量

int x = 42;
int *p = &x;     // p 存 x 的地址

*p = 7;           // 按地址改写 x
printf("%d", x);   // 输出 7

两个地址运算符

  • &x 取地址：得到 x 的门牌号（类比）
  • *p 解引用：顺着 p 存的地址读写目标
  • 声明写作 int *p；32 位 STM32 上指针占 4 字节
  • 本节只要求看懂 & 与 *，不深入指针运算

传值 vs 传址：为什么需要指针

传值：函数内改的是副本

void swap_bad(int a, int b)
{
    int t = a; a = b; b = t;
}
swap_bad(x, y);   // x y 不变

传址：按地址改原件

void swap_ok(int *a, int *b)
{
    int t = *a; *a = *b; *b = t;
}
swap_ok(&x, &y);  // 交换成功

想让函数修改某个变量，就把它的地址传进去。scanf("%d", &score) 里的 & 同理

多文件：.h 是接口，.c 是实现

mymath.h（声明）

#ifndef MYMATH_H      // 防重复包含
#define MYMATH_H

int my_add(int a, int b);   // 函数原型

#endif

mymath.c（实现）+ main.c（调用）

#include "mymath.h"
int my_add(int a, int b)
{ return a + b; }

// main.c 调用，两个 .c 一起编译：
gcc main.c mymath.c -o mymath

.h 放函数原型、宏、类型定义（菜单）；.c 放函数实现（后厨）；每个模块一个 .c/.h 对，工程由多个模块组成

#include 与 #define 宏

#include 两种写法

<stdio.h> 尖括号：系统头文件目录

"mymath.h" 双引号：先找项目目录，再找系统目录

#define 常量宏

#define MAX_SPEED 6600   // 改一处全改

本质是预处理阶段的文本替换；末尾不要写分号

#define 函数宏与括号坑

#define SQ(x) ((x) * (x))    // 正确
#define SQ2(x) x * x         // 错误示范

SQ2(1 + 2)  // 展开 1+2*1+2 = 5，期望 9
10 / SQ2(2)  // 展开 10/2*2 = 10，期望 2

宏的参数和整体都必须加括号

常见错误与排查

现象可能原因排查方法
error: expected ';' ...上一行漏分号检查报错行的上一行
undefined reference to ...函数未实现，或 .c 没一起编译检查实现与编译命令
双击 exe 一闪而过程序结束窗口关闭在终端运行，或加 getchar();
输出中文乱码终端与文件编码不一致统一为 UTF-8
程序卡住不结束循环条件永远成立检查条件与更新语句
Segmentation fault数组越界或野指针打印下标与地址检查
输出结果莫名不对if 里把 == 写成 =搜索 if ( 内的单等号
宏展开后数值不对宏少括号 / 末尾多了分号参数与整体都加括号
