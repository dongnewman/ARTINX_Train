## 核心概念

### 0. 为什么电控要学 C？

机器人听不懂人话，它只认一串串指令。C 语言就是把你的想法「翻译」成机器指令的那门语言。
STM32 单片机（就是一块小电脑）的开发主力语言就是 C，战队框架的底层驱动（BSP / CubeMX 生成的那部分）也都是 C 写的；上层的算法、组件、消息（`algorithm` / `components` / `message` 目录）则用 C++（`.hpp`/`.cpp` + 类）。本节先打好 C 的基础，C++ 的类等你打开战队工程时再补也不迟。
先在本节学会「用 C 在电脑上写程序」，下一节再把同样的语法搬到单片机上。

**一句话总结：C 是跟单片机说话的通用语言，先学说话，再学开车。**

### 1. Hello World —— 第一个程序

打开 VS Code，新建 `hello.c`，输入：

```c
#include <stdio.h>          /* 引入「标准输入输出」工具包，printf 就住在里面 */

int main(void)              /* main 是程序入口：运行程序就是从这里开始 */
{
    printf("Hello, ARTINX!\n");  /* 打印一行字，\n 表示换行 */
    return 0;               /* 告诉操作系统：我正常结束 */
}
```

编译并运行（终端里执行）：

```bash
gcc hello.c -o hello    # 编译：把 .c 翻译成可执行文件
./hello                 # 运行
```

预期输出：

```
Hello, ARTINX!
```

逐行拆解：

| 代码 | 含义 |
|---|---|
| `#include <stdio.h>` | 把系统自带的「输入输出工具包」拿进来，才能用 `printf` |
| `int main(void)` | 程序入口，程序从这里开始执行 |
| `printf("...")` | 打印内容，`\n` 是换行符 |
| `return 0;` | 正常结束，把 0 还给操作系统 |
| 每条语句结尾 `;` | 像句号，忘记写会编译报错 |

> 💡 类比：写程序就像写信。`main` 是信的正文起点，`;` 是句号，`{}` 是大括号包裹的一个段落。

**一句话总结：程序从 main 开始执行，printf 负责说话，分号是句号。**

### 2. 变量与数据类型：贴标签的盒子

**生活类比**：变量就像超市的储物盒——先买一个盒子、贴上标签（起名字），再把东西放进去（赋值）。
盒子的**大小**由「类型」决定：小盒子装不下大东西。

```
        int a = 42;
   ┌───────┬───────┬───────┬───────┐
   │  42   │       │       │       │   ← 标签：a，盒子大小：4 字节
   └───────┴───────┴───────┴───────┘
```

STM32 开发里最常用的三种盒子：

| 类型 | 占多大 | 装什么 | 例子 |
|---|---|---|---|
| `char` | 1 字节 | 一个字符 / 小整数 | `'A'`、`'\n'` |
| `int` | 4 字节（32 位平台上） | 整数，约 ±21 亿 | `42`、`-100` |
| `float` | 4 字节 | 小数（约 6~7 位有效数字） | `3.14f` |

> 嵌入式里还会见到 `uint8_t`、`int16_t` 这类「固定宽度类型」（用 `#include <stdint.h>` 引入），
> 它们的宽度在任何平台上都一样，后续写单片机代码时会经常用到，现在先认识即可。

变量三步曲：**声明（买盒子贴标签）→ 赋值（放东西）→ 使用（拿出来用）**。

```c
#include <stdio.h>

int main(void)
{
    int  speed = 3000;      /* 声明 + 初始化：买个 int 盒子，标签 speed，放 3000 */
    char team  = 'A';       /* char 盒子：放一个字符，字符要用单引号 */
    float ratio = 0.5f;     /* float 盒子：小数后面加 f 表示 float */

    speed = 2500;           /* 重新赋值：把盒子里的旧东西倒掉，放新的 */

    printf("speed = %d\n", speed);   /* %d 是整数占位符 */
    printf("team  = %c\n", team);    /* %c 是字符占位符 */
    printf("ratio = %.2f\n", ratio); /* %.2f 是小数占位符，保留 2 位 */
    return 0;
}
```

常用占位符：`%d` 整数、`%c` 字符、`%f` 小数、`%s` 字符串。`printf` 就像填空题，`%d` 是空格，逗号后面依次填入。

命名规则（标签怎么贴）：

- 只能由字母、数字、下划线组成，不能以数字开头；
- 不能和关键字重名（`int`、`for`、`if`…）；
- 惯例：见名知意，如 `motor_speed` 比 `a` 好一百倍。

**一句话总结：变量 = 贴标签的盒子，类型决定盒子大小，先声明再赋值。**

### 3. if / switch：人生的分岔路口

**生活类比**：走到岔路口，看路标决定往哪走。`if` 就是那个路标——条件成立走一条路，不成立走另一条。

```c
#include <stdio.h>

int main(void)
{
    int score = 85;

    if (score >= 60)          /* 条件成立吗？成立就进这个门 */
    {
        printf("及格！\n");
    }
    else                      /* 否则进这个门 */
    {
        printf("不及格\n");
    }

    /* 多级路口：if - else if - else 级联 */
    if (score >= 90)      printf("等级 A\n");
    else if (score >= 80) printf("等级 B\n");
    else if (score >= 70) printf("等级 C\n");
    else if (score >= 60) printf("等级 D\n");
    else                  printf("等级 F\n");
    return 0;
}
```

关系运算符：`==` 相等、`!=` 不等、`>` `<` `>=` `<=`。
逻辑运算符：`&&` 并且、`||` 或者、`!` 取反。例如 `if (x > 0 && x < 10)` 表示 x 在 0 和 10 之间。

> **提醒**：`=` 是**赋值**，`==` 才是**判断相等**。写 `if (x = 0)` 不是「x 等于 0 吗」，而是「把 0 放进 x，条件恒为假」。编译器常常不报错，只会让你的程序「莫名奇妙」。

当一个变量被检查很多次时，用 `switch` 更清晰：

```c
#include <stdio.h>

int main(void)
{
    int level = 2;   /* 比如：遥控器的档位 1 / 2 / 3 */

    switch (level)               /* 看 level 是几，跳到对应的 case */
    {
    case 1:  printf("低速挡\n"); break;
    case 2:  printf("中速挡\n"); break;
    case 3:  printf("高速挡\n"); break;
    default: printf("未知挡位\n"); break;   /* 都不是时走这里 */
    }
    return 0;
}
```

`switch` 两件事必须记住：

1. `case` 后面只能跟**常量**（整数或字符），不能写范围；
2. 每个 `case` 结尾要写 `break;`——忘记写会「贯穿」，把下一个 case 也执行了（有时是故意的，但新手先一律写）。

**一句话总结：if 是岔路口，switch 是多选一，比较用 == 而不是 =。**

### 4. for / while：转圈干活

**生活类比**：循环就是「重复做同一件事」。像军训报数：第 1 圈报 1，第 2 圈报 2……直到第 100 圈结束。
`for` 适合「知道要转几圈」，`while` 适合「转到条件不满足为止」。

**for 的三要素**：初始（从哪开始）、条件（到哪结束）、更新（每圈怎么变）。

```c
#include <stdio.h>

int main(void)
{
    /*  ①初始 i=1   ②条件 i<=100    ④每圈结束 i++（i 加 1） */
    int sum = 0;
    for (int i = 1; i <= 100; i++)
    {
        sum = sum + i;   /* ③循环体：这一圈要干的活 */
    }
    printf("1 加到 100 = %d\n", sum);   /* 5050 */
    return 0;
}
```

执行顺序是 ① → ② → ③ → ④ → ② → ③ → ④ → … 直到条件不成立。

`while` 版本：

```c
#include <stdio.h>

int main(void)
{
    int i = 1, sum = 0;
    while (i <= 100)       /* 只要条件成立，就一直转 */
    {
        sum = sum + i;
        i++;
    }
    printf("sum = %d\n", sum);
    return 0;
}
```

两个控制语句：

- `break;` —— 立刻跳出整个循环（比如「找到目标了，收工」）；
- `continue;` —— 跳过本轮剩下内容，直接开始下一圈（比如「这圈不合格，下一圈」）。

> 与 STM32 的关系：单片机的程序几乎都有一个「死循环」——`while (1) { ... }`，
> 表示「上电后永远重复执行这一段」。这是后面每一节都会见到的写法，现在先混个脸熟。

**一句话总结：for 知道转几圈，while 转到条件不成立，break 跳车，continue 快进。**

### 5. 函数：榨汁机

**生活类比**：榨汁机——你从一头**放入原料（参数）**，机器**内部加工（函数体）**，另一头**流出果汁（返回值）**。
你不需要知道机器内部怎么转，只要知道放什么、拿什么。

```
 苹果 ×2（参数） ──▶ [ 榨汁机（函数体）] ──▶ 一杯果汁（返回值）
```

```c
#include <stdio.h>

/* 榨汁机：放两个 int，流出较大的那个 */
int max2(int a, int b)      /* 返回类型 int | 函数名 max2 | 参数 a、b */
{
    if (a > b) return a;    /* return：把结果交出去，函数立刻结束 */
    return b;
}

int main(void)
{
    int bigger = max2(3, 7);        /* 调用：把 3 和 7 塞进去 */
    printf("较大的数是 %d\n", bigger);   /* 7 */
    return 0;
}
```

函数四要素：

| 要素 | 说明 | 例子 |
|---|---|---|
| 返回类型 | 流出什么类型的东西；不流出写 `void` | `int` |
| 函数名 | 见名知意 | `max2` |
| 参数 | 放进来的原料，多个用逗号隔开 | `int a, int b` |
| 函数体 | 加工过程，`return` 交货 | `{ ... }` |

**为什么要写函数：有一些对程序的处理需要重复执行很多次，如果可以“一次写好，多次使用”，就可以大大减少重复开发，还有整理程序的可理解性和简洁性。**

### 6. 数组：一排连号储物柜

**生活类比**：数组是一排**连号的储物柜**，共用一个名字，用编号（下标）区分。
注意：编号从 **0** 开始——第一个柜子是 0 号柜。

```
   int arr[5] = {10, 20, 30, 40, 50};
   ┌─────┬─────┬─────┬─────┬─────┐
   │ 10  │ 20  │ 30  │ 40  │ 50  │
   └─────┴─────┴─────┴─────┴─────┘
     0     1     2     3     4      ← 下标（0 号柜开始！）
```

```c
#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};  /* 5 个柜子，一次放满 */

    printf("0 号柜：%d\n", arr[0]);     /* 10 */
    arr[2] = 99;                        /* 往 2 号柜重新放东西 */
    printf("2 号柜：%d\n", arr[2]);     /* 99 */

    /* 循环 + 数组 = 黄金搭档：挨个开柜子 */
    int total = 0;
    for (int i = 0; i < 5; i++)
    {
        total += arr[i];    /* total = total + arr[i] */
    }
    printf("合计：%d\n", total);        /* 249 */
    return 0;
}
```

`for` 和数组天生一对：`i` 从 0 转到 4，`arr[i]` 就是挨个开柜子。单片机里常见「一圈传感器数据」「电机历史记录」都是数组。

> 常见问题：下标范围是 `0 ~ 4`，访问 `arr[5]` 是**越界**——柜子根本没有 5 号。C 语言不会拦你，
> 程序可能读到垃圾值、可能当场崩溃，也可能「碰巧正常」。这叫**未定义行为**，是最难查的 bug 之一。

**一句话总结：数组 = 连号储物柜，下标从 0 数，越界是未定义行为。**

### 7. struct：学生档案袋

**生活类比**：一个学生的信息有姓名、学号、成绩——类型各不相同，装在**一个档案袋**里方便整体传递。
`struct`（结构体）就是把多种类型打包成一个新类型。

```c
#include <stdio.h>
#include <string.h>          /* strcpy 住在这里 */

/* 定义档案袋模板：里面有哪些格子 */
struct Student
{
    char  name[16];          /* 姓名：一串字符 */
    int   id;                /* 学号 */
    float score;             /* 成绩 */
};

int main(void)
{
    struct Student s1;                 /* 按模板做一个档案袋 */
    strcpy(s1.name, "小明");           /* 字符串不能直接 =，要用 strcpy 复制 */
    s1.id    = 20260101;
    s1.score = 88.5f;

    printf("%s 的成绩是 %.1f\n", s1.name, s1.score);  /* 用 . 取出格子里的东西 */
    return 0;
}
```

在机器人里，struct 无处不在：一个电机的状态 = 电流 + 转速 + 角度 + 温度，打包成一个结构体传来传去，
比一堆散装变量清爽得多（讲解时结合战队现有代码展示）。

**一句话总结：struct = 档案袋，把不同类型的字段打包成一个整体，用 . 取字段。**

### 8. enum：选择题卡

**生活类比**：enum（枚举）就像答题卡——选项只有固定的 A、B、C、D，不能填别的。
把「只能是这几个值」的变量限制在固定选项内，代码可读性大增。

```c
#include <stdio.h>

/* 定义选项：默认从 0 开始自动编号 RED=0, GREEN=1, BLUE=2 */
enum Color { RED, GREEN, BLUE };

int main(void)
{
    enum Color led = GREEN;           /* 只能选选项里的值 */

    if (led == GREEN)
        printf("绿灯亮\n");

    printf("GREEN 的编号是 %d\n", led);   /* 1 */
    return 0;
}
```

也可以手动指定编号：`enum Mode { STOP = 0, FOLLOW = 1, TRACK = 2 };`——比如云台的模式：
停止 / 跟随 / 追踪。用 `enum` 比满屏的 `0 1 2` 魔法数字好读得多。

**一句话总结：enum = 选择题卡，把变量限定在固定几个选项里，可读性++。**

### 9. 指针基本概念：门牌号

**生活类比**：变量是房间里的东西，**指针是房间的门牌号**。
你不需要把整间房搬给别人，只要把门牌号给他，他就能顺着地址找到房间、改里面的东西。

```
   内存（一排带门牌号的房间）：
   门牌 0x100 ┌────────┐
              │  42    │  ← int x = 42
   门牌 0x104 ├────────┤
              │ 0x100  │  ← int *p = &x （p 里存的是 x 的门牌号）
              └────────┘
```

两个新符号：

- `&x` —— **取门牌号**：问「x 住在哪」，得到 x 的地址；
- `*p` —— **按门牌号进屋**：顺着 p 存的地址，找到那间房，读写里面的东西。

```c
#include <stdio.h>

int main(void)
{
    int x = 42;
    int *p = &x;         /* p 是一个「门牌号变量」，存的是 x 的地址 */

    printf("x 的值：%d\n", x);          /* 42 */
    printf("x 的地址：%p\n", (void *)&x); /* 一串十六进制，如 0x7ffc... */

    *p = 7;              /* 顺着门牌号进屋，把 7 放进去 */
    printf("改完 x：%d\n", x);          /* 7 */
    return 0;
}
```

**为什么要指针——传值 vs 传址**。默认函数传参是「复印件」：函数里改的是复印件，原件纹丝不动。
想改原件，就把门牌号（地址）传进去：

```c
#include <stdio.h>

void swap_bad(int a, int b)   /* 传值：改的是复印件 */
{
    int t = a; a = b; b = t;
}

void swap_ok(int *a, int *b)  /* 传址：按门牌号改原件 */
{
    int t = *a; *a = *b; *b = t;
}

int main(void)
{
    int x = 3, y = 5;

    swap_bad(x, y);    /* 没效果 */
    printf("swap_bad 后：x=%d y=%d\n", x, y);   /* 3 5 */

    swap_ok(&x, &y);   /* 把两间房的门牌号交出去 */
    printf("swap_ok  后：x=%d y=%d\n", x, y);   /* 5 3 */
    return 0;
}
```

> 本节只要求到「基本概念」：认识 `&` 取地址、`*` 解引用、传值与传址的区别即可。
> 二级指针、指针运算等留到以后需要时再深入。指针很强大，也最容易出错——不要怕，先会用门牌号。

**一句话总结：指针 = 门牌号，& 问门牌，* 进门，传值改复印件，传址改原件。**

### 10. 多文件：.h 是菜单，.c 是后厨

**生活类比**：餐厅把「有什么菜」写在**菜单**上给顾客看（.h），把「菜怎么做」藏在**后厨**（.c）。
顾客（别的 .c 文件）只需要看菜单点菜，不用进后厨。

- **`.h` 头文件**：只写**声明**——函数长什么样（名字、参数、返回类型），像菜单上的菜名；
- **`.c` 源文件**：写**实现**——函数真正怎么干，像后厨的菜谱。

`mymath.h`（菜单）：

```c
#ifndef MYMATH_H            /* 这三行是「菜单防重复发放」守卫，先照抄 */
#define MYMATH_H

int my_add(int a, int b);   /* 声明：告诉顾客有这道菜，具体做法在后厨 */

#endif
```

`mymath.c`（后厨）：

```c
#include "mymath.h"         /* 后厨师傅自己也要看一眼菜单 */

int my_add(int a, int b)    /* 实现：真正做菜 */
{
    return a + b;
}
```

`main.c`（顾客）：

```c
#include <stdio.h>
#include "mymath.h"         /* 点菜：先看菜单 */

int main(void)
{
    printf("3 + 4 = %d\n", my_add(3, 4));   /* 7 */
    return 0;
}
```

编译时把两个 .c 一起交给 gcc：

```bash
gcc main.c mymath.c -o mymath
./mymath
```

`#include` 的两种写法：

- `#include <stdio.h>` —— 尖括号：去**系统工具包**目录里找（编译器自带的标准库）；
- `#include "mymath.h"` —— 双引号：先在**自己项目目录**里找，找不到再去系统目录找。

>真实项目里一个功能一个 .c/.h（如 `motor.c` / `motor.h`），职责清楚、好找 bug。
> 这一节之后看战队代码，你会发现整个工程就是几十上百个 `.c/.h`（底层 BSP）加 `.hpp/.cpp`（上层算法与组件）组成的（讲解时结合战队现有代码展示）。

**一句话总结：.h 是菜单只写声明，.c 是后厨写实现，尖括号找系统，双引号找自己。**

### 任务二：判断——成绩评级

题目：写程序读入一个 0~100 的整数成绩，输出等级 A（≥90）/ B（≥80）/ C（≥70）/ D（≥60）/ F（<60）。

```c
#include <stdio.h>

int main(void)
{
    int score;
    printf("输入成绩(0~100): ");
    scanf("%d", &score);        /* &score：把输入放进 score 这个盒子（& 是取门牌号） */

    if (score >= 90)      printf("等级 A\n");
    else if (score >= 80) printf("等级 B\n");
    else if (score >= 70) printf("等级 C\n");
    else if (score >= 60) printf("等级 D\n");
    else                  printf("等级 F\n");
    return 0;
}
```

- 预期现象：输入 85 → `等级 B`；输入 59 → `等级 F`；输入 100 → `等级 A`。
- 自查点 ✔：试了边界值 90、89、60、59；知道 `scanf` 里的 `&` 是什么作用。

### 任务三：循环——从 1 加到 100，再打九九乘法表

题目 A：用 for 计算 1+2+…+100，输出 5050。
题目 B（挑战）：两重循环打印九九乘法表。

```c
#include <stdio.h>

int main(void)
{
    /* A：累加 */
    int sum = 0;
    for (int i = 1; i <= 100; i++) sum += i;
    printf("1~100 的和 = %d\n", sum);      /* 5050 */

    /* B：九九乘法表（外层控制行 i，内层控制列 j） */
    for (int i = 1; i <= 9; i++)
    {
        for (int j = 1; j <= i; j++)
        {
            printf("%d*%d=%d\t", j, i, j * i);   /* \t 是对齐用的制表符 */
        }
        printf("\n");                          /* 一行打完换行 */
    }
    return 0;
}
```

- 预期现象：A 输出 5050；B 输出 9 行三角形排布的乘法表。
- 自查点 ✔：能把 for 的三个要素指出来；能解释外层、内层循环各控制什么。

### 任务四：函数——写一个「榨汁机」

题目：写函数 `int max2(int a, int b)` 返回较大值；再写 `int max3(int a, int b, int c)`，**内部调用 max2** 实现。

```c
#include <stdio.h>

int max2(int a, int b)
{
    return (a > b) ? a : b;   /* 三元运算符：条件 ? 取这个 : 取那个 */
}

int max3(int a, int b, int c)
{
    return max2(max2(a, b), c);   /* 榨汁机套榨汁机：先比前两个，再和 c 比 */
}

int main(void)
{
    printf("max3(3, 9, 5) = %d\n", max3(3, 9, 5));   /* 9 */
    return 0;
}
```

- 预期现象：输出 9。
- 自查点 ✔：能说出 max2 的参数、返回值各是什么；理解「函数里再调函数」。

### 任务五：综合——学生成绩单（数组 + struct + 函数）

题目：用 struct 存 3 名学生的姓名、学号、成绩；写函数求平均分；打印成绩单。

```c
#include <stdio.h>

struct Student
{
    char  name[16];
    int   id;
    float score;
};

/* 求平均分：参数是一袋学生档案，n 是袋子里有几个人 */
float avg_score(struct Student s[], int n)
{
    float total = 0.0f;
    for (int i = 0; i < n; i++)
    {
        total += s[i].score;
    }
    return total / n;
}

int main(void)
{
    struct Student class[3] = {         /* 结构体数组：3 个档案袋连成一排 */
        {"小明", 20260101, 88.5f},
        {"小红", 20260102, 92.0f},
        {"小刚", 20260103, 79.5f}
    };

    for (int i = 0; i < 3; i++)
    {
        printf("%s 的成绩：%.1f\n", class[i].name, class[i].score);
    }
    printf("平均分：%.1f\n", avg_score(class, 3));   /* 86.7 */
    return 0;
}
```

- 预期现象：打印 3 行成绩 + 1 行平均分 86.7。
- 自查点 ✔：能解释 `class[i].score` 是什么；知道 `avg_score(class, 3)` 传的是什么。

## 常见问题与排查

| 现象                                  | 可能原因                     | 排查方法                                             |
| ----------------------------------- | ------------------------ | ------------------------------------------------ |
| 编译报 `expected ';' before ...`       | 上一行漏了分号                  | 看报错指出的行号的**上一行**                                 |
| 编译报 `undefined reference to my_add` | 只写了 .h 声明，没实现或没把 .c 一起编译 | 检查函数是否实现；编译命令是否带上了所有 .c                          |
| 双击 exe 一闪而过                         | 程序跑完窗口立即关闭               | 在终端里 `./hello` 运行，或在 `return 0;` 前加 `getchar();` |
| 输出数字明显不对                            | `%d` 与变量类型不匹配            | 核对占位符：整数 `%d`、小数 `%f`、字符 `%c`                    |
| 程序卡住一直跑                             | 循环条件写错，永远成立              | 检查循环条件与更新语句（i++ 写了没）                             |
| 崩溃 / 报 `Segmentation fault`         | 数组越界或指针指向了野地址            | 打印下标与地址，检查访问范围                                   |
| `gcc` 不是内部或外部命令                     | gcc 未安装或 PATH 未配置        | 回看 1.1 环境配置，重新安装 MSYS2 + gcc 并配置 PATH            |
| `if (x = 0)` 行为诡异                   | 把 `==` 写成 `=`            | 全文件搜索 `if (` 里的单等号                               |
