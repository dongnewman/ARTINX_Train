电机（Motor）：把电能变成转动

电机是将电能转换为机械能（旋转运动）的执行器，机器人所有轮子与关节的动力来源。可类比肌肉。

概念定义要点
直流无刷 BLDC无碳刷换向的直流电机，换相由电调完成寿命长、效率高
KV 值每伏电压对应的空载转速（rpm/V）电压越高转得越快
减速箱齿轮组，减速比 N:1转速 ÷N，扭矩约 ×N
堵转（stall）负载过大卡死，转速为 0电流飙升发热，电调保护

口诀：转得快就没力气，有力气就转不快，减速箱在两者之间做交换。

电调（ESC）：翻译官兼驾驶员

电调（Electronic Speed Controller，调速器）接收 CAN 数字指令，用 FOC 算法控制三相电流，驱动无刷电机。

电机配套电调控制量类型控制量含义
M3508C620（一对一）电流 int16正负号决定方向，绝对值决定出力
M2006C610（一对一）电流 int16
GM6020内置驱动器电压 int16正负号决定方向，绝对值决定出力
  • 无刷电机需按顺序给三相线换相通电，此工作由电调完成；普通电机靠碳刷，会磨损。
  • FOC（磁场定向控制）：让磁场始终与转子成最佳角度发力，转动平稳高效。
  • 电调同时监测温度与过流，异常时自动保护——驾驶员的一面。

编码器（Encoder）：电机的里程表

编码器是装在电机上的角度传感器，测量转角与转速，数据经 CAN 反馈帧上报主控。可类比里程表。

反馈帧字段内容说明
字节 0~1机械角度0~8191 对应一圈 0~360°
字节 2~3转速单位 rpm，int16，可负
字节 4~5实际电流跟随控制量，越接近越好
字节 6温度过高应降负载（单位以手册为准）
  • 增量式：只数步数，上电不知位置，需校准（M3508 / M2006 配合电调使用）。
  • 绝对式：上电即知绝对位置（GM6020 内置编码器）。
  • 反馈约 1 kHz（每 1 ms 一帧），控制周期与之对齐才能闭环。

CAN（Controller Area Network）：整车神经总线

CAN 是汽车工业成熟的总线：一条双绞线挂所有设备，广播收发，常用速率 1 Mbps。可类比班级群聊。

  • ID 双作用：地址——设备只收发给自己的 ID；优先级——仲裁时 ID 小者先发。

标准数据帧：8 字节承载一切

段长度含义
SOF 帧起始1 位广播开始标志
ID 仲裁段11 位地址＋优先级，0~2047
控制段 DLC4 位数据段长度，这里为 8 字节
数据段0~8 字节控制量 / 反馈量，高字节在前（大端）
CRC 校验段15 位收方验算，错误则丢弃
EOF 帧结束7 位ACK 应答＋结束标志
帧类型ID数据段
控制帧（C620 / C610）0x200（ID 1~4）/ 0x1FF（ID 5~8）4 组 int16 电流
反馈帧（C620 / C610）0x200 + 电机ID（如 0x201）角度 / 转速 / 电流 / 温度
控制帧（GM6020）0x1FF / 0x2FF4 组 int16 电压
反馈帧（GM6020）0x204 + 电机ID角度 / 转速 / 电流 / 温度

以上约定以官方手册为准；演示页提供帧的逐段展开动画。

控制量 vs 反馈量：命令与实况

控制量是主控发给执行器的命令（目标电流 / 电压，int16）；反馈量是传感器报回的实际状态（角度、转速、电流、温度）。

模式机制受扰动后类比
开环只发命令，不看反馈偏了就偏了，无人纠正蒙眼开车
闭环每周期读反馈、算误差、修命令自动修正睁眼开车
误差 = 目标 − 实际。闭环的「边看边修」算法即 1.5 节 PID；任务四将现场感受开环局限。

IMU（惯性测量单元）与姿态角

IMU（Inertial Measurement Unit）集成陀螺仪与加速度计，解算设备当前姿态角。可类比手机里的陀螺仪。

角度动作机器人里的用法
Yaw 偏航左右摇头底盘朝向、云台水平旋转
Pitch 俯仰上下点头云台上下打角（最常用）
Roll 翻滚左右歪头车身倾角、坡道检测
  • 陀螺仪测角速度：响应快但会漂移；加速度计测重力方向，用于纠偏；两者融合得姿态角。
  • 不同设备坐标轴定义可能不同，接入新 IMU 先读官方手册确认轴方向与旋转顺序。

动手实践：四个任务

任务做什么观察点 / 自查点
任务一 获取反馈解析 0x201 反馈帧并打印角度随手动旋转变化，数据不乱跳
任务二 控制旋转发 0x200，目标电流 3000平稳转动，反馈 speed 与控制量同号
任务三 修改方向控制量取负（−3000）反转，反馈 speed 为负

任务一：获取电机反馈（解析帧）

  • 接线：24 V 供电、电调 CAN 线接主控 CAN 口、总线两端终端电阻、波特率 1 Mbps。
  • 收到 ID 为 0x201 的帧即解析：数据段 8 字节，高字节在前（大端）。
// 解析反馈帧：ID = 0x200 + 电机ID（1 号 → 0x201）
typedef struct { uint16_t angle; int16_t speed; int16_t current; uint8_t temp; } MotorFB;
MotorFB parse(uint8_t d[8]) {        // 高字节在前（大端）
  MotorFB fb;
  fb.angle   = (d[0] << 8) | d[1];             // 机械角度 0~8191
  fb.speed   = (int16_t)((d[2] << 8) | d[3]);  // 转速 rpm
  fb.current = (int16_t)((d[4] << 8) | d[5]);  // 实际电流
  fb.temp    = d[6];                            // 温度
  return fb;
}
// 主循环：rx = can_receive(); 若 rx.id == 0x201 则 printf(fb)；
// 战队实际接收 / 打印函数以现有工程为准（讲解时展示）。

自查：ID 正确、角度随手动旋转变化、数据不乱跳（乱跳查波特率与解析错位）。

任务二：控制电机旋转（发控制帧）

  • 控制量：目标电流 int16，正＝正转、负＝反转；起步用小值 3000。
  • 控制帧 ID 0x200 一帧控制 ID 1~4 电机，约 1 kHz 周期发送。
// 发送控制帧：让 1 号电机以 3000 电流转动
int16_t current = 3000;            // 控制量：正=正转 负=反转

while (1) {
  uint32_t id   = 0x200;           // 发给 ID 1~4（5~8 用 0x1FF）
  uint8_t  data[8] = {0};
  data[0] = (current >> 8) & 0xFF; // 高字节在前（大端）
  data[1] =  current       & 0xFF;
  can_send(id, data);              // 战队实际发送函数占位
  delay_1ms();                     // 1 kHz 指令流（以手册为准）
}

自查：平稳转动不抖、反馈 speed 与控制量同号、温度不快速上升。

任务三：修改电机方向

  • 改法：控制量取负（+3000 → −3000），重新编译烧录，电机反向旋转。
  • 原理：电调把控制量符号翻译成三相电流方向，符号反则转向反。
  • 机械装反的纠正：该电机控制量乘 −1（或使用战队封装中的方向参数）。
  • 约定：以官方手册「面向输出轴逆时针为正」统一整车方向定义。
int16_t current_target = -3000;  // 反转：控制量取负
// 装反纠正示意：current_target = -original;  // 统一方向
检查：反转后反馈 speed 为负；整车四轮方向约定一致，否则底盘会「打架」。

任务四：修改控制量

  • 阶梯测试：3000 → 6000 → 9000 → 12000，记录各档反馈 speed 与 current，转速逐档加快。
  • 开环实验：固定 6000 轻捏输出轴，转速骤降甚至停转——命令不变，无人纠偏。
  • 限幅：控制量超合法范围时电调按上限处理或进入保护，输出不允许无限大。
实验控制量预期现象实测记录（转速 / 电流 / 温度）
基准+3000正向平稳转动
反向−3000反向转动
阶梯+6000 / +9000 / +12000转速逐档加快
开环+6000 并轻捏输出轴转速明显下降

记录开环现象：这是 1.5 节 PID 要解决的第一个问题。

常见问题与排查

心法：现象 → 分层 → 假设 → 验证。按供电层、通信层、指令层、机械层逐层排除。

现象可能原因排查方法
电机完全不动供电 / CAN 线 / 控制量 0 / ID 错查指示灯 → 换线 → 打印发出的帧
收不到反馈帧波特率不对 / 缺终端电阻 / ID 看错核对 1 Mbps；补终端电阻；确认 0x200+ID
电机转了但方向反控制量符号 / 安装约定不一致控制量取负再试，统一整车方向
转速忽快忽慢发送周期不稳 / 总线冲突 / 供电不足稳定 1 kHz 发送；量供电电压
发烫 / 有焦味电流过大 / 满载 / 堵转立即断电，查机械卡阻，降控制量
转着转着停了堵转保护 / CAN 掉线超时保护查卡阻与 CAN 线是否松动压断
